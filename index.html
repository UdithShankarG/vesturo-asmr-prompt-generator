⚠️ Known AI Video Generation Problems (Auto-Prevented in Prompts)

  • Object morphing instead of mechanical unfolding — prompt enforces rigid mechanical movements only
  • Text/numbers appearing on screen — prompt explicitly forbids any on-screen text or measurements
  • Object sliding or drifting on surface — prompt locks base position throughout video
  • Lighting/shadow inconsistency — prompt demands fixed, consistent lighting
  • Hand continuity errors — prompt specifies consistent hand appearance
  • Part count changing between frames — prompt enforces conservation of parts
  • Camera teleportation or zoom — prompt locks single handheld perspective
  • Material/color shifting — prompt demands consistent metallic finish throughout
  • Unnatural physics (floating parts) — prompt demands true physics simulation
  • Sound without visual cause — prompt syncs every sound to a visible action
